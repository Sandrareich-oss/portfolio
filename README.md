# Портфолио — Александра, Product Designer

Статический одностраничный сайт-портфолио (single-page, один HTML-файл).

## Структура

```
Портфель/
├─ site/
│  ├─ index.html                     # сам сайт (HTML + CSS + JS + изображения в base64)
│  └─ assets/                        # внешние медиа: mockup.png, mockup-main.png, block-1.png, formula-editor.png, fbd-editor.mp4
├─ serve.ps1                         # локальный запуск (Python http.server + браузер)
├─ Александра — Product Designer (1).html   # исходный экспорт (не изменялся)
├─ Александра — Product Designer(1).md      # текстовая версия контента
└─ Запись экрана 2026-11-12 в 22.46.51.mov  # видеозапись (референс)
```

## Запуск

```powershell
.\serve.ps1            # http://127.0.0.1:4173
.\serve.ps1 -Port 8080 # другой порт
```

Либо вручную:

```powershell
python -m http.server 4173 --directory site
```

## Особенности

- **Нет сборки и зависимостей.** Открывается двойным кликом по `site/index.html`, но сервер предпочтительнее: у ссылки на CV PDF открывается встроенный просмотрщик через `blob:`-URL.
- **Изображения** (фото + превью кейсов) встроены в HTML как `data:image/webp;base64` — сайт работает офлайн.
- **Мокап с видео** в кейсе FBD-редактора — отдельные файлы в `site/assets/`: рамка монитора `mockup.png` и запись `fbd-editor.mp4` (H.264, 720p), которая автоматически проигрывается в «экране» мокапа.
- **Шрифты** (Onest, Oswald, IBM Plex Mono) подгружаются с Google Fonts — без интернета используются системные фолбэки.
- **Тёмная тема** включается автоматически по `prefers-color-scheme`, есть ручной переключатель в шапке.
- **CV** — PDF зашит в HTML (`#cv-pdf`) и скачивается/открывается без отдельного файла.

## Деплой

Достаточно залить содержимое `site/` (файл `index.html` и папку `assets/`) на любой статический хостинг:
GitHub Pages, Netlify, Vercel, Cloudflare Pages — без настроек сборки.
