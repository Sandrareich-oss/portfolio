# Портфолио — Александра, Product Designer

Статический одностраничный сайт-портфолио (single-page, один HTML-файл).

## Структура

```
Портфель/
├─ site/
│  ├─ index.html                     # сам сайт (HTML + CSS + JS + изображения в base64)
│  ├─ assets/                        # внешние медиа: mockup.png, mockup-main.png, block-1.png, formula-editor.png, fbd-editor.mp4
│  ├─ monitor-demo.html               # кликабельный прототип «Монитора», встроен в кейс 1
│  └─ demo-assets/                    # логотип и аватар прототипа
├─ serve.ps1                         # локальный запуск (Python http.server + браузер)
├─ Александра — Product Designer (1).html   # исходный экспорт (не изменялся)
├─ Александра — Product Designer(1).md      # текстовая версия контента
└─ Запись экрана 2026-11-12 в 22.46.51.mov  # видеозапись (референс)
```

## Запуск

```powershell
.\serve.ps1            # http://127.0.0.1:4173
.\serve.ps1 -Port 8080 # другой порт
```

Либо вручную:

```powershell
python -m http.server 4173 --directory site
```

## Особенности

- **Нет сборки и зависимостей.** Открывается двойным кликом по `site/index.html`, но сервер предпочтительнее: у ссылки на CV PDF открывается встроенный просмотрщик через `blob:`-URL.
- **Изображения** (фото + превью кейсов) встроены в HTML как `data:image/webp;base64` — сайт работает офлайн.
- **Мокап с видео** в кейсе FBD-редактора — отдельные файлы в `site/assets/`: рамка монитора `mockup.png` и запись `fbd-editor.mp4` (H.264, 720p), которая автоматически проигрывается в «экране» мокапа.
- **Кликабельный прототип** встроен в кейс «Мониторинг документов» через iframe: можно кликать по строкам таблицы, пользоваться фильтрами и смотреть плавный прогресс передачи. Отдельно открывается по ссылке «Открыть на весь экран» (`monitor-demo.html`).
- **User Flow** в кейсах «Мониторинг документов» и FBD-редактора — SVG-схема, которая собирается по мере прокрутки: блоки проявляются, стрелки дорисовываются, шкала внизу показывает прогресс. В мониторинге показаны четыре зоны: авторизация, работа с таблицей, детали отправления и формирование отчётов. Схема растягивается по ширине экрана, поэтому текст не мельчает; при `prefers-reduced-motion` показывается целиком без анимации. На экранах ≤860px scroll-анимация отключается: схема видна сразу и прокручивается по горизонтали внутри своего блока.
- **Адаптив** — три брейкпоинта: ≤1120px (плотнее сетка и отступы), ≤860px (одна колонка, статичный User Flow, контент без sticky-сайдбара), ≤600px и ≤400px (смартфоны: компактная типографика, кнопки в две равные колонки, кейсы с уменьшенными полями). Горизонтальной прокрутки страницы нет ни на одном размере.
- **Шрифты** (Onest, Oswald, IBM Plex Mono) подгружаются с Google Fonts — без интернета используются системные фолбэки.
- **Тёмная тема** включается автоматически по `prefers-color-scheme`, есть ручной переключатель в шапке.
- **CV** — PDF зашит в HTML (`#cv-pdf`) и скачивается/открывается без отдельного файла.

## Деплой

Сайт опубликован на GitHub Pages: https://sandrareich-oss.github.io/portfolio/

Деплой автоматический: при каждом push в `main` workflow `.github/workflows/deploy.yml` берёт содержимое папки `site/` (файлы `index.html`, `monitor-demo.html` и папки `assets/`, `demo-assets/`) и публикует его на Pages. Сборка не нужна — можно запустить и вручную через `workflow_dispatch` во вкладке Actions.

Для другого статического хостинга (Netlify, Vercel, Cloudflare Pages) достаточно указать `site/` как корень публикации — без настроек сборки.
